# Day 04 - Smart Doorbell System

## Objective
To build a smart doorbell system using an Arduino Uno, push button, and piezo buzzer in Tinkercad.

---

## Components Used
- Arduino Uno
- Breadboard
- Push Button
- Piezo Buzzer
- 10kΩ Resistor
- Jumper Wires

---

## Circuit Connections

### Push Button
| Component | Arduino Pin |
|-----------|-------------|
| Push Button | Pin 2 |
| Other Side | 5V |
| Pull-down Resistor | GND |

### Piezo Buzzer
| Component | Arduino Pin |
|-----------|-------------|
| Positive (+) | Pin 8 |
| Negative (-) | GND |

---

## Working Principle

- Press the push button → Buzzer turns ON.
- Release the push button → Buzzer turns OFF.

The Arduino continuously reads the button state and controls the buzzer accordingly.
