# Day 02 - Traffic Light Controller

## Objective
To design and simulate a traffic light controller using Arduino and LEDs in Tinkercad.

---

## Components Used
- Arduino Uno
- Breadboard
- Red LED
- Yellow LED
- Green LED
- 220Ω Resistors
- Jumper Wires

---

## Circuit Connections

| LED | Arduino Pin |
|-----|--------------|
| Red LED | Pin 13 |
| Yellow LED | Pin 12 |
| Green LED | Pin 11 |

Each LED is connected in series with a resistor and GND.

---

## Working Principle

The Arduino controls three LEDs sequentially to simulate a real traffic light system.

### Sequence
1. Red LED ON
2. Yellow LED ON
3. Green LED ON
4. Repeat continuously

Timing is controlled using delay functions.
